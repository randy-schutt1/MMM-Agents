## WHY THIS EXISTS

Judgement words left unexamined follow a predictable path into doctrine: the agent
needs something codable, picks a threshold that fits the examples it happened to
see, and within a few phases that number is enforced by Pine Script and validated
by a backtest fitted to the same data. Nobody can then remember it was invented.

This log stops that early by keeping judgement **visibly** judgement.

Governing decision: `DECISIONS.md` D-010 (machine-rule firewall).
