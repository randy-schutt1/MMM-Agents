# 02_TRANSCRIPTS

Timestamped transcripts, one folder per lesson.

## STATUS: EMPTY — NO LESSON TRANSCRIBED

## STRUCTURE

```text
02_TRANSCRIPTS/
└── VXX/
    └── VXX_TRANSCRIPT.md
```

Lesson folders are created as each lesson is started — not pre-created for a lesson
count that has not been verified.

## RULES

- Template: `00_SYSTEM/TEMPLATES/TRANSCRIPT_TEMPLATE.md`
- Timestamps `[HH:MM:SS]` at every topic change and every rule statement.
- Mark uncertainty: `[unclear]`, `[inaudible NN sec]`, `[?word?]`.
- Note what is on screen when it matters: `[on screen: ...]`, `[chart: ...]`.
- Flag homework inline with `[HOMEWORK]`.
- **Never silently invent missing speech.** A marked gap is evidence; a smooth
  fabrication is corruption of the corpus.
- A partial transcript must say so in its coverage block. An unmarked partial reads
  as complete to the reviewer.
- Transcription is not comprehension. The transcript is raw material; the lesson's
  operational meaning is captured in `03_LESSON_NOTES/`.
