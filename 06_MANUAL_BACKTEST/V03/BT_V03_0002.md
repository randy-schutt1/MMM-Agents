# BT_V03_0002 — PT-020: the London-open asymmetric conditional

> ## ⚠ MANDATORY SCOPE STATEMENT — `PT-020` §6, verbatim
>
> PT-020 tests a **broad reading** of one V03 conditional, using the Asian range as the
> referent for *"the high"* and *"the low"*. `A-006` (what "the box" is), `A-002` (trap
> move), `A-049`/`C-006` (stop hunt versus trap) and `A-001` (the anchor, on which the
> narrow reading depends) all remain **open**, and this test closes none of them. It is not
> a test of the Market Maker Method entry rule, which additionally requires an M/W second
> leg and TDI.

> ## ⚠ THE INTERPRETIVE DEPENDENCY — `PT-020` §3b, declared before the result
>
> `V03_INTERPRETATION.md` `I8` reads this conditional **narrowly** — scoped to a week whose
> bias is already short — and records that the broad symmetric reading is defensible, that
> the choice was the interpreter's, and that a reviewer disagreeing *"changes condition table
> row 1's scope"*. **This test uses the broad reading**, because the narrow reading requires
> knowing the week's bias at 03:30, which requires the anchor point (`A-001`), which is
> undefined — so the narrow reading is **not testable today**. **The result is therefore
> evidence about the broad reading only, and is silent about the narrow one.**

### Two readings the pre-registration did not state, declared rather than silently chosen

1. **"Inside the trigger window"** is taken to mean the 15m bar's **stamp** lies in
   [03:30, 04:30) — stamps 03:30, 03:45, 04:00, 04:15, whose closes fall at 03:45 … 04:30.
2. **`PT-020` §3 lists three branches as though disjoint**, but a day can breach both edges
   inside one hour. The day is assigned by **whichever edge is breached first**, which uses
   only information available at the decision point. Days breaching both are counted and
   reported: **1 (Arm A) / 4 (Arm B)** — small enough that the choice cannot drive anything.

### Baselines — all run and printed before branch H's result was read

| Arm | What was run |

| **Second — the natural control** | **Branch N days entered short at 04:30.** Isolates the breach from the hour |
| **Third — the direction-symmetry control** | **The mirror rule: long after a low-side breach.** `PT-020` §4: *"The third arm is the sharpest. The rule's whole claim is that the two sides are **not** mirror images; running the mirror is the cheapest way to find out"* |

**The conditional fires on 61% (Arm A) / 67% (Arm B) of days, and stands aside on 34–36%.**
This is not a rare setup; it is a rule about most days. **The low side fires more often than
the high side on both arms** (0.338 vs 0.270; 0.355 vs 0.318), so *"forget it"* discards more
opportunities than *"you sell"* creates.

## 2. THE VARIANCE CLAIM — REPORTED FIRST, AS `PT-020` §3 REQUIRES. **CONTRADICTED IN DIRECTION**

The instructor's stated reason is **epistemic**, not directional: *"I don't know if it's a
straightaway or if it's a stop hunt."* `PT-020` §1 makes the prediction precise: **the
low-side branch should show *higher dispersion*, not merely worse returns.**

| Dispersion of the outcome | Arm A | Arm B |
|---|---|---|
| Branch **H** — SD | **29.47** | **31.08** |
| Branch **L** — SD | **28.54** | **28.80** |
| L − H (SD), permutation two-sided p | −0.94, **p = 0.572** | −2.28, **p = 0.097** |
| Branch **H** — IQR | **64.10** | **68.00** |
| Branch **L** — IQR | **42.30** | **41.97** |
| L − H (IQR), permutation two-sided p | −21.80, **p = 0.493** | −26.03, **p = 0.098** |
| N1 dispersion null (outcome SD) | 29.56 [27.32, 31.06] (H) · 29.49 [27.60, 30.92] (L) | — |
| Branch SD percentile vs its own null | H 48.2 · L 19.2 | H 94.1 · L 22.2 |

> ### **Branch L is the *less* dispersed branch, on both arms, on both dispersion measures.**
>
> The claim predicts branch L should be the uncertain one. In this sample **branch H is more
> dispersed than branch L on every measure and on both arms** — SD by 0.94 / 2.28 pips, IQR by
> 21.8 / 26.0 pips. Neither difference is significant (p = 0.572 / 0.097 on SD; 0.493 / 0.098
> on IQR), so the honest statement is:
>
> **The variance claim is not supported, and what signal there is runs the opposite way.**
>
> `PT-020` §5's row *"Branch H beats N1; branch L shows visibly higher dispersion → the
> conditional holds, asymmetry and all — the strongest available V03 result"* **does not
> fire.** Branch L's dispersion sits at the **19th / 22nd percentile** of its own null.
>
> **One measurement note, recorded rather than hidden.** A median-based scale test degenerates
> on this data and returned `p = 1.000` by construction: the modal outcome *is* the 18-pip
> stop, so the median absolute deviation is 0.00 in every branch. The mean-absolute-deviation,
> SD-difference and IQR-difference permutation tests were run together to replace it, and all
> three are reported. None was selected for its result.

## 3. THE DIRECTIONAL HALF — AND THIS IS WHERE THE ARMS DIVERGE

**Arm A (`UTC−5`)**

| | Branch H (short after high breach) | Branch L (same short, taken anyway) |
|---|---|---|
| n | 138 | 173 |
| target / stop / open | 35 / 89 / 14 | 38 / 116 / 19 |
| **Hit rate (of resolved)** | **0.282 (35/124)** [0.211, 0.367] | **0.247 (38/154)** [0.185, 0.320] |
| **Expectancy** | **+2.25 pips** [−2.67, +7.41] | **+0.66 pips** [−3.40, +4.95] |
| Percentile vs its own N1 (hit / exp) | **49.2 / 40.4** | 16.0 / 16.0 |

**Arm B (`America/New_York`)**

| | Branch H | Branch L |
|---|---|---|
| n | 163 | 182 |
| target / stop / open | 51 / 95 / 17 | 41 / 126 / 15 |
| **Hit rate (of resolved)** | **0.349 (51/146)** [0.277, 0.430] | **0.246 (41/167)** [0.186, 0.316] |
| **Expectancy** | **+6.31 pips** [+1.43, +10.96] | **+0.09 pips** [−4.00, +4.22] |
| Percentile vs its own N1 (hit / exp) | **95.8 / 94.8** | 13.4 / 11.0 |

> ### **The `D-031` divergence is the sharpest single finding in this test.**
>
> On **Arm A**, branch H is **at the middle of its own null** — percentile 49.2 on hit rate,
> 40.4 on expectancy. Nothing at all.
>
> On **Arm B**, the identical construction sits at **percentile 95.8 on hit rate and 94.8 on
> expectancy** — hit rate clearing the null's 95th percentile, expectancy one-fifth of a
> percentile short of it, and an expectancy confidence interval that excludes zero
> (+1.43 to +10.96 pips).
>
> **Same price path, same days, same rule. The clock moved one hour and a null became a
> near-significant positive.**
>
> **The pre-registered rule is not "take the better arm".** `D-031` is explicit that
> divergence is a **finding, never a selection criterion**, and that reporting only the
> better-performing arm is `E09` + `E24`. **The overall verdict is therefore
> `INDISTINGUISHABLE FROM THE NULL`** — one arm clears nothing, and even the favourable arm's
> expectancy does not clear 95.
>
> **What the divergence itself finds:** for a rule keyed to *"the beginning of the London
> session"*, an hour of ambiguity in where that beginning sits is the difference between a
> null and a result. **`A-019` and `C-004` are not bookkeeping details for this rule; they are
> load-bearing.**

**Branch L is roughly flat on both arms** — +0.66 and +0.09 pips, percentiles 16.0 / 11.0.
So *"forget it"* avoids a trade that loses approximately nothing. **Standing aside on the low
side costs the opportunity and saves no money**, at this sample, under the broad reading.

## 4. THE SECOND AND THIRD BASELINES

**Second — the natural control (branch N, short at 04:30):**

| | Arm A | Arm B |
|---|---|---|
| n | 201 | 167 |
| Hit rate | 0.230 (41/178) [0.175, 0.297] | 0.299 (43/144) [0.230, 0.378] |
| Expectancy | −0.25 pips [−4.00, +3.31] | +3.58 pips [−0.69, +8.41] |
| Outcome SD / IQR | 27.96 / 38.70 | 29.87 / 68.00 |

On Arm B the *no-breach* control returns +3.58 pips — more than half of branch H's +6.31 —
which means **a substantial part of branch H's Arm-B result is the hour, not the breach.**
`PT-020` §4 built this arm to isolate exactly that, and it bites.

**Third — the direction-symmetry control (the mirror: long after a low breach). `PT-020` §4
calls it the sharpest arm:**

| | Arm A | Arm B |
|---|---|---|
| n | 173 | 182 |
| Hit rate | 0.199 (31/156) [0.144, 0.268] | 0.261 (43/165) [0.200, 0.332] |
| Expectancy | **−2.87 pips** [−6.97, +1.09] | **+0.87 pips** [−3.36, +5.20] |
| Outcome SD / IQR | 26.48 / 21.40 | 28.98 / 38.40 |

**Branch H and the mirror are the same trade on opposite edges** — both fade the breakout back
into the range. Branch H: 0.282 / +2.25 and 0.349 / +6.31. Mirror: 0.199 / −2.87 and 0.261 /
+0.87.

> **Fading a high breach outperforms fading a low breach on both arms**, by 5.1 / 8.8
> percentage points of hit rate and 5.1 / 5.4 pips of expectancy.
>
> `PT-020` §4's test — *"If the mirror performs like branch H, the asymmetry is in the
> instructor's framing rather than in GBP/USD"* — **returns: the mirror does not perform like
> branch H.** So the asymmetry has **some** empirical content on this instrument in this
> window, consistently in the direction the instructor asserts.
>
> **This is the most favourable thing in the test and it still is not evidence.** Neither
> branch H clears its null on Arm A, the mirror difference was not itself tested against a
> null, and Arm B's branch-H advantage is partly the hour (§4, second baseline). It is
> recorded as a **direction that survived three controls without ever reaching significance**,
> which is a hypothesis for a later, better-powered test — not a result.

## 6. RULE APPLICATION VERSUS OUTCOME

- **Rule application: fully mechanical, no discretion.** Branch membership is a function of
  closes inside a fixed hour; direction, stop and target are fixed. Nothing was judged.
- **Days excluded: only for coverage, counted and labelled** (§0). Branch N is reported as a
  branch, not discarded.
- **Losers retained.** 89 / 95 branch-H stop-outs and 116 / 126 branch-L stop-outs are in §3;
  positions still open at 17:00 are marked to market.
- **The stand-aside branch was actually priced** — the only way to measure what a prohibition
  avoids.
- **No parameter was adjusted.** Window, branches, 18/50, the sub-window split, the seed and
  the iteration count are exactly as pre-registered.
- **Costs not modelled** (bid data); all expectancies are upper bounds by ~1–2 pips of spread.
  Branch H's Arm-B +6.31 survives that; Arm A's +2.25 does not.

## 7. WHAT THIS OBSERVATION DOES AND DOES NOT ESTABLISH

**Does:**
- **The variance claim — the distinctive half of this conditional — is not supported, and the
  point estimates run the opposite way on both arms.** Branch L is *less* dispersed than
  branch H (SD 28.54 vs 29.47 and 28.80 vs 31.08; IQR 42.30 vs 64.10 and 41.97 vs 68.00),
  with branch L's dispersion at percentile 19.2 / 22.2 of its own null.
- **The directional half diverges between `D-031` arms**: branch H at percentile 49.2 / 40.4
  on Arm A and **95.8 / 94.8 on Arm B**. Overall verdict `INDISTINGUISHABLE FROM THE NULL`;
  the divergence is the finding.
- **Standing aside on the low side saves nothing** — branch L taken anyway returns +0.66 /
  +0.09 pips.
- **The mirror does not perform like branch H** (0.199 / 0.261 vs 0.282 / 0.349), so the
  asymmetry has directional content on both arms — consistently, and never significantly.
- **On Arm B the no-breach control returns +3.58 pips**, so much of branch H's Arm-B result is
  the hour rather than the breach.
- **The `C-004` halves disagree, and reverse between arms.** Recorded against `C-004`;
  resolves nothing.
- The conditional fires on 61–67% of days; the stand-aside branch is the more frequent one.

**Does not:**
- Test the **narrow** reading (`I8`), which needs `A-001` and is untestable today (`PT-020`
  §3b). **This result is silent about it.**
- Resolve `C-004`, or close `A-001`, `A-002`, `A-006`, `A-019`, `A-049` or `C-006`.
- Test the Market Maker Method entry rule.
- License trading branch H. Its favourable arm is one of two, and partly the hour.
- Generalise beyond GBP/USD, 2014-01-05 → 2015-12-31, and the V02 printed box.
