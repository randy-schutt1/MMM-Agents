# 07_MASTERY_REPORTS

Student self-assessment, one report per lesson: `VXX_MASTERY_REPORT.md`.

## STATUS: EMPTY — NO LESSON ASSESSED

## WHAT A MASTERY REPORT IS

A **self-assessment and a submission for review**. It is not an authorization to
advance. Only a reviewer `PASS` in `18_REVIEW/REVIEW_INDEX.md` permits progression
(`DECISIONS.md` D-004, `SETUP_ISSUES.md` I-001/I-004).

## STATUS VALUES

```text
PASS             ← student believes all ten dimensions are satisfied; submits for audit
REVIEW REQUIRED  ← uncertain about one or more dimensions, or work incomplete
BLOCKED          ← cannot complete: unusable source, foundational confusion,
                   or dependence on an unmastered earlier lesson
```

## THE TEN DIMENSIONS

A. Recall · B. Recognition · C. Discrimination · D. Sequence · E. Exceptions ·
F. Homework · G. Manual backtesting · H. Provenance · I. Ambiguity ·
J. Contradictions

Full definitions: `00_SYSTEM/MASTERY_STANDARD.md`.

## WRITE IT HONESTLY

An adversarial reviewer will inspect the source independently. Overstating mastery
does not survive that — it costs a review cycle and puts a `REVISE` in the
permanent record.

An honest `REVIEW REQUIRED` is worth more to this project than an optimistic
`PASS`. In particular, do not: claim recognition demonstrated only on lesson
examples; describe an inferred rule as explicit instruction; omit an embarrassing
backtest observation; call a vague citation provenance; or call reconstructed
homework a first-pass success.

## REVISIONS

Append a `## Revision R<n>` section. Never overwrite the original assessment — the
progression from first submission to `PASS` is part of the learning record.
