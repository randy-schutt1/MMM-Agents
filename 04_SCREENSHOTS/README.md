## RULES

- **Screenshots are first-class evidence.** The reviewer audits chart recognition
  against them.
- Do not capture merely because a slide changed. Capture what is needed to
  reconstruct the teaching.
- Descriptor states what is **shown**, not what it means:
  - `V07_00-43-12_three-push-example.png` — good
  - `V07_00-43-12_perfect-entry-signal.png` — bad, that is interpretation
- **An unindexed image is not evidence.** Every file appears in `INDEX.md` with
  timestamp, concept, what to notice, rule supported, classification, and related
  homework.
- Screenshots **are** committed to Git (unlike source video). The repository is
  private (`DECISIONS.md` D-013).

## NEVER

Do not substitute a generated, illustrative, or reconstructed image for a real
course screenshot — under any circumstances, for any reason. A fabricated image
presented as course evidence is a research-integrity failure, not a shortcut.

If frame extraction is unavailable, say so in the index, reference
`SETUP_ISSUES.md` I-006, and flag the limitation to the reviewer.
