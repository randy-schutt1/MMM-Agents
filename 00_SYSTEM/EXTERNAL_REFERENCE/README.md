## ⚠️ THE PROVENANCE WARNING ON THE PDF — READ BEFORE QUOTING IT

The file arrived named *"Steve Mauro ORIGINAL The Market Maker Method BTMM.pdf"*. **The document
itself does not claim to be Mauro's.** Its own title page reads:

> *The Market Maker Method — Private Study Notes from Seminar of Steve Mauro —
> **Authored by: Anonymous***

So it is **an anonymous student's notes about a seminar**, not a work by the instructor. That
places it in the *same reliability class* as the Studocu / Course Hero / PDFCoffee material
already catalogued in `../EXTERNAL_VOCABULARY_REFERENCE.md` §4 — and, on internal evidence
(identical phrasing, identical 30–90 minute figure, identical section ordering), it is very
probably the **upstream original** that much of that web material was copied from.

That cuts both ways and both directions matter:

- **It is better than the web sources**, because it is complete, coherent, internally consistent,
  and evidently written by someone who sat through the seminars. It is the single most
  informative external document about this vocabulary found anywhere.
- **It is not more authoritative than them**, because it is the *same source*. Agreement between
  this PDF and a web page is **not** independent corroboration — it is one document quoted twice.
  Any earlier note claiming web-source convergence on a term this PDF also covers should be
  read down accordingly.
- **It is not the course.** It describes seminars, not the recordings in `01_SOURCE_VIDEOS/`.
  Where it and a lesson differ, the lesson is the corpus and this is commentary.
